# Создание WordPress темы на основе HTML сайта

## Цель проекта
Создать полнофункциональную WordPress тему, визуально идентичную исходному HTML сайту, с возможностью управления контентом через административную панель WordPress версии 6.9.1.

## Исходные данные
- Папка `html_sources` - исходный сайт в формате HTML (НЕ ИЗМЕНЯТЬ)
- Папка `wp_theme/1expertnsk` - целевая папка для WordPress темы
- Папка `wp_content` - папка для HTML кода страниц WordPress

## Требования к реализации

### 1. Структура темы WordPress
- Создать все необходимые файлы темы WordPress в папке `wp_theme/1expertnsk`
- Обязательные файлы: `style.css`, `index.php`, `header.php`, `footer.php`, `functions.php`
- Создать шаблоны страниц в соответствии с имеющимися на исходном сайте
- Ориентироваться на функциональность WordPress 6.9.1

### 2. Визуальное воспроизведение
- Точное воспроизведение всех визуальных элементов исходного сайта
- Создание CSS с нуля (без копирования готовых файлов)
- Адаптивный дизайн в соответствии с исходным сайтом
- Кроссбраузерная совместимость (Chrome, Firefox, Safari, Edge)

### 3. Динамические элементы
- Реализовать возможность создания новых страниц через WordPress
- Автоматическое добавление новых страниц в меню
- Управление контентом страниц через редактор WordPress
- Управление контактными данными через Customizer

### 4. Динамические области шапки и подвала
- В шапке и подвале реализовать динамические области для виджетов
- Использовать стандартные функции WordPress для добавления меню:
  - `register_nav_menus()` для регистрации областей меню
  - `wp_nav_menu()` для отображения меню
- Создать области виджетов с помощью `register_sidebar()`
- Обеспечить визуальное соответствие динамических элементов дизайну исходного сайта
- Не копировать статические пункты меню из исходного сайта, а создавать динамические структуры

### 5. Функциональные требования
- Главное меню сайта управляется через WordPress Menus
- Сайдбар(ы) при необходимости реализуются через Widgets
- Контактная информация редактируется через Customizer
- Все изображения загружаются через Media Library WordPress

## Этапы реализации

### Этап 1: Анализ исходного сайта
- Изучение структуры и дизайна исходного HTML сайта
- Определение всех визуальных компонентов
- Создание карты страниц и шаблонов
- Выявление областей для динамических элементов

### Этап 2: Создание базовой структуры темы
- Создание необходимых PHP файлов темы
- Реализация основного каркаса сайта (header, footer, меню)
- Настройка functions.php для поддержки необходимых функций
- Регистрация областей меню и виджетов
- Ориентироваться на функциональность WordPress 6.9.1

### Этап 3: Реализация стилей
- Создание style.css с нуля
- Реализация всех визуальных элементов исходного сайта
- Стилизация динамических элементов под дизайн исходного сайта
- Обеспечение адаптивности

### Этап 4: Создание шаблонов страниц
- Реализация всех необходимых шаблонов
- Настройка динамического отображения контента
- Интеграция с системой управления WordPress
- Реализация динамических меню и виджетов

### Этап 5: Тестирование и финальная настройка
- Проверка корректности отображения во всех браузерах
- Тестирование функциональности динамических элементов
- Проверка совместимости с WordPress 6.9.1
- Оптимизация производительности

## Критерии приемки
- Тема корректно отображается во всех современных браузерах
- Все визуальные элементы исходного сайта воспроизведены
- Возможность создавать и редактировать страницы через WordPress
- Автоматическое добавление страниц в меню
- Управление контактными данными через интерфейс WordPress
- Динамические меню и виджеты в шапке и подвале функционируют корректно
- Тема использует только функции, доступные в WordPress 6.9.1
- Тема проходит валидацию WordPress Theme Checker

В данном проекте несколько папок:
- `html_sources` - это папка с исходным сайтом в формате html, дизайн и контент которого мы будем воспроизводить. Делать изменения в этой папке - запрещено. Она должна сохраниться полностью.
- `wp_theme/1expertnsk` - это папка, в которую мы будем генерировать php код для темы wordpress, которая будет копировать дизайн исходного сайта. Тема должна называться 1expertnsk
- `wp_content` - это папка, в которой мы будем создавать html код для страниц wordpress, чтобы воспроизвести контент исходного сайта в оформлении wp_theme
